# VideoShorts Studio — 商业模式与产品规划

## 你要的模式（一句话）

**卖一个很便宜的终身软件（¥5–10）**；用户要么 **自己买 API Key（BYOK）** 免你用他的额度，要么 **向你买 Token（按量扣费）** 图省事。  
你主要赚：**软件买断费 +（可选）Token 差价**，不默认替所有人垫 API。

---

## 两种收费方式（给用户选）

| | **A. 自带 Key（BYOK）** | **B. 平台 Token（向你买）** |
|--|-------------------------|------------------------------|
| 软件价 | ¥5–10 终身买断 | 同上，或略贵（¥15–29 含赠送额度） |
| API 费用 | 用户自己去通义/Groq 充值 | 在你这买 Token，按次/按分钟扣 |
| 你的成本 | 几乎为 0 | 通义/Groq 账单 + 支付通道 |
| 适合谁 | 会注册阿里云、想最便宜 | 不想折腾 Key、小商家 |
| 你的风险 | 低 | 需控价、防刷、对账 |

**产品原则：** 安装包里 **永不内置你的 Key**；BYOK 的 Key 只存用户本机；Token 模式走你的 **账号体系 + 余额**。

---

## 你怎么赚钱（算清账）

### 路径 A — 只卖软件（最简单）

- 收入：¥5–10 × 销量（闲鱼/微店/发卡网）
- 用户：自己申请 `DASHSCOPE_API_KEY`，在软件「设置」填写
- 功能：**本地裁剪 / 抖音包 / 电商基础** 永久免 Key；AI 功能用用户自己的 Key，**不经过你**

### 路径 B — 软件 + Token（利润更高，要做后端）

- 收入：买断费 + Token 充值（例如 ¥10 充 1000 点）
- 你拿 **批发价** 调通义/Groq，对用户 **零售价** 扣点（加价 20%–50% 或按「每次 AI 切片」定价）
- 需在软件里：**登录 → 余额 → 扣点 → 你服务器代调 API**

### 建议组合（现实可落地）

1. **第一版只上 A**：快速验证有人愿意为 ¥5–10 买单  
2. **第二版加 B**：有 50+ 付费用户后再做 Token 钱包（避免一开始就被 API 账单拖垮）

## 产品形态（一个 EXE，可扩展）

```
VideoShorts Studio.exe
├── 免费/买断壳：场景工作台 + 本地引擎（FFmpeg）
├── 授权：机器码 / 激活码（终身）
├── 模式 A：设置页填用户自己的 API Key → user.env
└── 模式 B（后期）：账号登录 + Token 余额 + 云端代调用
```

## 功能规划（按场景，覆盖抖音 / 电商 / 通用）

### 第一层：零 Token、零 Key（必做，支撑 ¥5 买断）

| 功能 | 说明 | 平台 |
|------|------|------|
| 本地裁剪 | 时间段切 + 拼接 | 通用 |
| 抖音发布包 | 9:16、≤60s 校验、竖屏导出 | 抖音/快手/视频号 |
| 电商基础切片 | 手动切卖点段 + 竖屏 | 小店/直播切片 |
| 批量导出（Phase 2） | 文件夹排队 | 达人刚需 |

**卖点话术：** 「5 块钱终身，剪片不花 API 钱。」

### 第二层：BYOK 的 AI（有 Key 才能用，你不出钱）

| 功能 | 消耗 | 说明 |
|------|------|------|
| AI 智能切片 | 通义 +（可选）Groq 转录 | 长视频→多段短片 |
| 全片翻译配音 | 通义 + Groq/本地 Whisper | 跨境课/教程 |
| 字幕样式模板 |  mostly 本地 | Phase 2 |

**卖点话术：** 「AI 用你自己的通义，我们只卖工具。」

### 第三层：平台 Token（后期，向你买额度）

| 功能 | 扣点建议（示例） |
|------|------------------|
| AI 智能切片 1 次 | 50–100 点（¥0.5–1） |
| 翻译配音 1 分钟成片 | 30 点/分钟 |
| 本地裁剪 / 抖音包 | **不扣点**（引流） |

需配套：**注册、充值、账单、风控（日限额）**。

### 第四层：电商 / 抖音深化（差异化）

| Phase | 功能 |
|-------|------|
| 2 | 批量队列、片头片尾、字幕安全区 |
| 3 | 按停顿自动切讲解、主图 15s、价格字幕高亮 |
| 4 | 导出「平台规范说明」+ 文件夹命名规范（不代发布） |

### 模式 B 要新增（规划，不必第一版）

| 模块 | 作用 |
|------|------|
| 用户账号 | 手机/邮箱登录 |
| 钱包 | 余额、充值记录 |
| 计费网关 | 每次 AI 任务前扣点，失败退回 |
| API 代理 | 你的 Key 在服务端，用户不看见 |
| 管理后台 | 充值、封号、用量统计 |

**最小 Token 方案：** 不做全功能代理，只做「兑换码充点」+ 本地扣点计数 + 你手动在通义控制台看用量（极简版，适合刚开始）。

## 合规与风险（简短）

- **不代发抖音/不上传用户视频到你服务器**（模式 A 全本地）→ 隐私好讲  
- Token 模式需在用户协议写清：AI 由第三方提供、按量计费  
- 定价要覆盖：通义实际 token 费 + 支付手续费 + 恶意刷量缓冲
