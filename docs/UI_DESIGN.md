# VideoShorts Studio — 界面设计（Tauri + Vue）

## 产品定位（方案 A）

- **只卖软件**，终身买断；**API Key 仅用户填写**（设置页），开发者不托管。
- 第一版可导出：**本地裁剪、抖音发布包、电商基础切片**（无 Key）。
- AI / 翻译：界面预留，标注「需配置通义 Key」。

## 页面说明

### 1. 工作台 `/`

- 三张 **场景卡片**（推荐路径）：无 Key 剪片 / 抖音竖屏 / 电商切片
- 底部 **路线图** 折叠：AI、短剧、海报（即将推出）
- 显示：本机配置路径、FFmpeg 是否就绪（后续 Tauri 检测）

### 2. 本地裁剪 `/clip`

- 左：**选择视频**、**时间段**（多行）、选项（拼接顺序）
- 右：**说明**、**开始导出**、进度条、输出路径、打开文件夹

### 3. 抖音发布包 `/douyin`

- 同裁剪 + 强制 **9:16** + **总时长滑块**（默认 ≤60s）
- 顶部黄色提示条：平台规范摘要

### 4. 电商切片 `/ecommerce`

- 同裁剪 + 默认竖屏勾选
- 灰色信息卡：后续「按停顿自动切」规划

### 5. AI 智能切片 `/ai`（后续接 Rust/Python）

- 视频/链接、指令输入
- 横幅：**请先在设置中填写通义 API Key**
- 转录模式 Groq / 本地（占位）

### 6. 翻译配音 `/subtitle`（后续）

- 同上，固定流水线说明

### 7. 授权 `/license`

- 机器码（只读 + 复制）
- 激活码输入 + 激活按钮
- 免费版限额说明

### 8. 设置 `/settings`

- **通义 API Key**（密码框）
- **Groq API Key**（可选）
- 模型名、TTS 音色（占位）
- 保存说明：仅写入 `%APPDATA%\VideoShortsStudio\user.env`

## 组件规范

- 主按钮：实心 indigo，高 44px
- 次按钮：描边
- 输入：深色底 + 聚焦环主色
- 页面最大宽度：主内容 `1200px` 居中，避免超宽屏空洞

## 技术栈

- **Tauri 2**（Rust 壳，调用 `vsa-core`）
- **Vue 3** + **Vue Router** + **Vite**
- 样式：纯 CSS 变量（`theme.css`），无重型 UI 库，便于控体积
